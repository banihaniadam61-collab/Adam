# بَنْكُ امْتِحَانَاتِ «عُمْدَةِ الرَّاغِبِ»

صفحة HTML واحدة (تعمل بفتح `index.html` مباشرةً، بلا خادم) تعرض امتحانات مبنيّة على
«عمدة الراغب في مختصر بغية الطالب».

## نَوْعَا الْأَسْئِلَةِ

| النوع | السؤال | الجواب |
|---|---|---|
| `matn` | نصُّ المؤلِّف كما هو بين قوسين | الشرحُ كاملًا لذلك النصِّ بعينه |
| `word` | ما معنى كلمة كذا؟ | التعريفُ كما جاء في الشرح نفسه حرفيًّا — ولا يُوضع سؤالُ كلمةٍ إلا إذا عرَّفها الشرحُ صراحةً |

حواشي أسفل الصفحة تُوضَع في الحقل `note`: تظهر **مع** الجواب لكن في صندوقٍ منفصلٍ
مُعَنْوَنٍ بأنّها للمطالعة فقط وليست من الجواب.

كلُّ النصوص مشكولةٌ تشكيلًا كاملًا.

## بِنْيَةُ الْمِلَفَّاتِ

```
index.html            هيكل الصفحة
assets/style.css      التنسيق (فاتح/داكن، جوّال، طباعة)
assets/app.js         المحرّك: تنقّل، إظهار الأجوبة، تقييم ذاتيّ، بحث
data/00-manifest.js   بيانات الكتاب — يُنشئ window.EXAM_DATA
data/NN-*.js          ملفّ لكلِّ قسم، يدفع قسمًا في EXAM_DATA.sections
```

## شَكْلُ الْبَيَانَاتِ

```js
window.EXAM_DATA.sections.push({
  id: "creed",
  title: "قِسْمُ الْعَقِيدَةِ",
  pages: "١–١٣٠",
  exams: [
    {
      id: "creed-001-030-a",
      kind: "range",          // "range" لامتحان صفحاتٍ، "mixed" للشامل
      title: "الْعَقِيدَةُ — صَفَحَاتُ ١–٣٠ (الْجُزْءُ الْأَوَّلُ)",
      pages: "١–٣٠",
      questions: [
        { id: "c-p12-m1", type: "matn", page: 12,
          matn: "(نَصُّ الْمُؤَلِّفِ)", a: "الشَّرْحُ كَامِلًا…", note: "حَاشِيَةُ الصَّفْحَةِ…" },
        { id: "c-p12-w1", type: "word", page: 12,
          word: "الْكَلِمَةُ", a: "تَعْرِيفُهَا كَمَا فِي الشَّرْحِ.", note: "…" }
      ]
    }
  ]
});
```

`id` لكلِّ سؤالٍ يجب أن يكون فريدًا داخل الامتحان — يُستعمل لحفظ التقييم الذاتيّ في المتصفّح.

## خُطَّةُ الِامْتِحَانَاتِ

لكلِّ قسمٍ من أقسام الكتاب:

1. **امتحاناتُ الصفحات** — ١–٣٠، ٣١–٦٠، ٦١–٩٠… ويُقسَّم المدى إلى جزءٍ ثانٍ وثالثٍ
   عند كثرة الأسئلة، حتى لا يُترَك سؤالٌ ممكنٌ.
2. **الامتحاناتُ الشاملة** — أسئلةٌ مخلوطةٌ من القسم كلِّه (ص ١ وص ٧٣ وص ١٠٩ معًا).
